Understanding Page Replacement Algorithms

A guide to virtual memory principles, eviction heuristics, hardware complexity, and theoretical bounds.

FIFO (First-In, First-Out)

Queue Based

The operating system maintains a queue of all pages resident in memory. When a page fault requires replacement, the page at the head of the queue (the oldest loaded page) is selected as victim.

Time Complexity

O(1) with queue pointers / circular buffer.

Limitations

May evict frequently used modules merely because they were loaded early. Susceptible to Belady's Anomaly.

LRU (Least Recently Used)

Recency Based

Evicts the page that has not been accessed for the longest period of time, leveraging the principle of temporal locality (recent past predicts future access patterns).

Time Complexity

O(1) with hash map + doubly linked list; O(f) with scan.

Advantages

Proven to be a stack algorithm: completely immune to Belady's Anomaly.

Optimal (Belady’s MIN)

Theoretical

Replaces the page whose next reference occurs farthest in the future. If a page will never be used again, it is an immediate candidate for eviction.

Time Complexity

O(f · n) per reference simulation scan.

Theoretical Bound

Unrealizable in general operating systems because an OS cannot foresee future process requests. Serves as the gold standard benchmark.
