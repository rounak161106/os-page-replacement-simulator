Learn the three algorithms

FIFO evicts the page that has been in memory longest. It is simple, but can evict a page that is used constantly. Time O(1) per reference with a queue, O(f) with a frame scan.

LRU evicts the page unused for the longest time, betting that recent use predicts future use. It avoids Belady's anomaly. Time O(f) per reference with a scan; O(1) with a hash map and linked list.

Optimal evicts the page whose next use is farthest away. It needs the future, so it cannot run in a real OS, but it gives the minimum possible faults and is the benchmark for the others. Time O(f·n) per reference as written here.

f is the number of frames and n the length of the reference string. A replacement happens only when memory is full; loading into a free frame is a fault but not a replacement.
